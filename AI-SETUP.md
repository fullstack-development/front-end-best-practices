# Как подключить AI-инструкции к своему проекту

В этом репозитории собраны стандарты компании и часть из них собрана в виде инструкций для AI-агентов. Их можно использовать в VS Code Copilot, Cursor и Claude Code. Этот гайд объясняет, как настроить каждый инструмент. Если вы пользуетесь другим AI агентом, наверняка в нём есть аналогичные инструменты.

---

## Глобальные инструкции (AGENTS.md)

**Что это:** Файл [AGENTS.md](./AGENTS.md) содержит базовые правила. Загружается в каждый промпт к агенту.

**Как подключить:**

| Инструмент | Что сделать |
|------------|-------------|
| **GitHub Copilot** | Скопировать содержимое файла `AGENTS.md` в проект `.github/copilot-instructions.md` |
| **Cursor** | Скопировать `AGENTS.md` в корень проекта — Cursor читает его нативно |
| **Claude Code** | Скопировать содержимое файла `AGENTS.md` в файл `CLAUDE.md` в корне проекта |

---

## Тематические инструкции (файлы `*.instructions.md`)

**Что это:** Файлы с правилами для конкретной области (React, CSS и др.). Каждый файл содержит YAML-фронтматтер с метаданными — они определяют, когда инструкция загружается автоматически.

Два режима загрузки:
- **Автоматически по файлу** — когда агент работает с файлом, подпадающим под паттерн (`applyTo` / `globs` / `paths`)
- **По запросу** — агент сам выбирает нужную инструкцию по описанию (`description`), когда задача совпадает с темой

| Инструкция | Область | Автоматически для |
|------------|---------|-------------------|
| [React/react.instructions.md](./React/react.instructions.md) | React-компоненты | `**/*.tsx` |
| [CSS/css.instructions.md](./CSS/css.instructions.md) | Стили | `**/*.{css,module.css,scss}` |

**Как подключить в зависимости от инструмента:**

### GitHub Copilot

Скопировать нужные файлы в `.github/instructions/` своего проекта.
Фронтматтер с `applyTo:` уже прописан — Copilot подхватит правила автоматически.

```
your-project/
└── .github/
    └── instructions/
        ├── react.instructions.md
        └── css.instructions.md
```

### Cursor

Скопировать файлы в `.cursor/rules/`, переименовав расширение в `.mdc`.
Заменить `applyTo:` на `globs:` в фронтматтере:

```yaml
---
description: "..."
globs: "**/*.tsx"
---
```

### Claude Code

Скопировать файлы в `.claude/rules/`.
Заменить `applyTo:` на `paths:` в фронтматтере:

```yaml
---
description: "..."
paths: ["**/*.tsx"]
---
```

## Агент-ревьюер кода

**Что это:** [.github/agents/frontend-reviewer.agent.md](./.github/agents/frontend-reviewer.agent.md) — кастомный агент для проверки кода на соответствие стандартам. Умеет проверять как изменённые файлы (`git diff`), так и конкретный путь. Сам агент не привязан к каким либо стандартам, а ищет существующие файлы инструкций/правил в проекте и проверяет на соответствие им.

**Как вызвать:**

```
@frontend-reviewer
```
Проверяет все файлы, изменённые с последнего коммита.

```
@frontend-reviewer src/components/Button.tsx
```
Проверяет конкретный файл или папку.

**Как подключить в зависимости от инструмента:**

| Инструмент | Что сделать |
|------------|-------------|
| **GitHub Copilot** | Скопировать `.github/agents/frontend-reviewer.agent.md` в свой проект — вызывается через `@frontend-reviewer` |
| **Claude Code** | Скопировать в `.claude/commands/frontend-reviewer.md` — вызывается через `/frontend-reviewer` |
| **Cursor** | Файловых агентов нет. Добавить содержимое агента как `.cursor/rules/frontend-reviewer.mdc` с `alwaysApply: false` — вызвать через `@frontend-reviewer` в чате |

> **Важно:** Агент-ревьюер ищет инструкции в `.github/instructions/` — стандартном месте для Copilot. При переносе в другой инструмент нужно изменить путь поиска в файле агента на соответствующий: `.cursor/rules/` для Cursor или `.claude/rules/` для Claude Code.
