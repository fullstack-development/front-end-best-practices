## AI-инструкции для агентов

Часть стандартов этого репозитория оформлена в виде инструкций для AI-агентов. Это позволяет ИИ агентам следовать стандартам проекта при генерации кода. К сожалению практика показывает, что ИИ может галлюцинировать и следовать инструкциям не всегда. Но примерно в 80+ процентов случаях ИИ всё таки следует им, что сильно облегчает жизнь.

| Файл | Назначение |
|------|-----------|
| [AGENTS.md](./AGENTS.md) | Глобальные правила — загружаются в каждый промпт |
| [CSS/css.instructions.md](./CSS/css.instructions.md) | Правила для CSS-модулей и стилей |
| [React/react.instructions.md](./React/react.instructions.md) | Правила для React-компонентов |
| [.github/agents/frontend-reviewer.agent.md](./.github/agents/frontend-reviewer.agent.md) | Агент-ревьюер кода |

Как подключить эти инструкции к своему AI-инструменту: [AI-SETUP.md](./AI-SETUP.md)

## Contributing

Если вы хотите внести свой вклад в развитие наших стандартов, пожалуйста следуйте практике issue first. Перед тем, как создать pull request, заведите issue, подробно опишите, в чем проблема, и как ваша идея позволяет решить ее. Пропускать этап создания issue и сразу создавать pull request можно только в случаях, когда проблема и решение очевидны (например, опечатка или орфографическая ошибка).
